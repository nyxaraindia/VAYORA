# VAYORA

### One Kerala. Every Journey.

VAYORA is a unified public transportation
intelligence platform for Kerala.

## Pilot Region

Kanjirappally - Thampalakkad
Kottayam, Kerala, India.

## Applications

1. VAYORA Passenger
2. VAYORA Crew
3. VAYORA Connect
4. VAYORA Intelligence

## Technology

- Flutter
- Dart
- Python
- FastAPI
- PostgreSQL
- PostGIS
- OpenStreetMap

## Vision

Make Kerala's public transportation network
digitally visible, searchable and predictable.

120-Day Development Plan.
